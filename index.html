Common questions

Is my data safe?

Yes. Everything happens inside your browser using JavaScript — your file is never uploaded to a server or seen by anyone. You could disconnect from the internet after the page loads and it would still work.

What kind of files does it handle?

Any .xlsx, .xls, or .csv file — customer lists, sales logs, survey exports, inventory sheets, and similar row-and-column data.
